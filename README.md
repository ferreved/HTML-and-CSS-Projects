# HTML and CSS Projects

This repository contains my college course projects for learning and practicing HTML and CSS. Each project will live in its own folder and include a small, self-contained web page or set of pages demonstrating layout, responsive design, forms, and other front-end skills.

What you'll find here

- Project folders named by number and short title (for example: `project-01-landing-page`).
- Each project includes:
  - `index.html` — the HTML entry point
  - `styles.css` (or a `css/` folder) — styling for the project
  - `assets/` — images, fonts, and other static files used by the project
  - A small project README describing the goal and how to view it locally

How to get a local copy (using GitHub Desktop)

1. Install GitHub Desktop (https://desktop.github.com/) if you don't already have it.
2. In GitHub Desktop, go to File → Clone repository.
3. Select the repository `ferreved/HTML-and-CSS-Projects` from the list or paste the clone URL: https://github.com/ferreved/HTML-and-CSS-Projects.git
4. Choose a local path and click "Clone".
5. Open the cloned folder in your code editor (VS Code, Sublime, etc.) and start working.

Workflow tips

- Create a new branch for each project or feature: `project-01` → make changes → commit → push → open a Pull Request on GitHub.
- Keep each project self-contained so it can be opened in the browser without additional setup.
