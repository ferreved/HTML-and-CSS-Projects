# Owner & Project Purpose

![Owner avatar](https://avatars.githubusercontent.com/u/214091557?v=4)

This repository (HTML-and-CSS-Projects) is used for my college course assignments and hands-on practice with HTML and CSS. Each project will be self-contained in its own folder and will demonstrate skills learned in the Version Control and Front-End courses, including:

- Responsive layouts and media queries
- Semantic HTML and accessibility basics
- CSS Grid and Flexbox
- Forms, validation, and UI components
- Project structuring and asset management

Folder structure for each project

- project-XX-short-title/
  - index.html — entry point
  - css/ (or styles.css) — styles
  - assets/ — images, fonts, icons
  - README.md — short description and how to view the project

How to view locally

1. Clone the repository with GitHub Desktop or git: `git clone https://github.com/ferreved/HTML-and-CSS-Projects.git`
2. Open the specific project folder (for example `project-01-landing-page`) and open `index.html` in your browser.

Notes
